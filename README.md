# AI Selling Video Director（AI 带货视频前期制作 Skill）

一个生成 AI 真人带货视频完整前期制作的 Skill。给它一个产品名称和一张产品图，它就能产出：

1. **主播方案**：AI 模特人设 + 主播三视图（正面/侧面/背面同一人物）
2. **分镜脚本与分镜图**：痛点 / 使用 / 推荐 / 效果 / 产品空镜五类画面
3. **视频生成提示词**：A-roll 口播 + B-roll 辅助镜头，全部可直接复制使用

当前版本：`1.0.0`

## 它解决什么问题

AI 视频能生成漂亮画面，但带货视频比画面更看重"可控"：

- 主播长什么样、穿什么、在哪个场景，能不能全片一致？
- 产品瓶盖该不该取下来、喷头是不是外露、画面里有几只手？
- 第 1 秒有没有声音？3 秒镜头塞得下 20 个字吗？
- 生成出来的视频是不是又被平台自动配了背景音乐？

这些踩坑经验，全部被编译成了 Skill 里的可执行规则。

## 不绑定视频模型：所有支持中文人声的模型都能用

本 Skill 产出的是**前期制作物料（主播图、分镜图、提示词）**，不绑定任何单一视频模型。

- A-roll 口播提示词：任何**支持中文人声 / 口播**的视频模型都可以用（Vidu、可灵、即梦、Seedance、Sora 等）；
- B-roll 纯画面素材提示词：所有图生视频模型都可以用；
- 只需要按各平台差异微调少量参数（时长上限、比例选项、是否默认配乐开关等）。

## 主要能力

- 主播三视图锚点：锁定人物多角度形象，换角度延展不易变形；
- 五类分镜画面：痛点 / 使用 / 推荐 / 效果 / 产品空镜，口播讲解 + 产品空镜穿插；
- 一个画面只放一个分镜内容（禁止左右分屏拼图）；
- 产品结构物理常识检查：喷头外露、瓶盖取下、开合结构与动作吻合；
- 肢体数量人工核验：多手、多指、错位全部拦截；
- 产品相对大小写真实比例：30ml 小瓶约占手掌一半，防画成巨瓶；
- 开场必须"有声"：第 1 秒就出口播，画外音 = 剪辑时把 A-roll 音轨垫到 B-roll；
- 台词-时长匹配：按每秒 4.5 字核算，3s≈13 字 / 4s≈18 字 / 5s≈22 字；
- 全部提示词强制"无背景音乐"，并提醒关闭平台 BGM 开关；
- 可选：生成一条适配垫乐（无人声，B-roll 明显、A-roll 压到 15-20% 不压人声）；
- 交付用「视频段｜素材图｜提示词」对照表格，提示词与素材图一一对应。

## 安装

### Codex

克隆仓库，把 Skill 文件夹放进 Codex Skills 目录：

```bash
git clone https://github.com/nutllwhy/doubao-ai-selling-video.git
cp -R doubao-ai-selling-video/doubao-ai-selling-video ~/.codex/skills/
```

### 其他 Agent

将 `doubao-ai-selling-video` 文件夹放进当前 Agent 支持的 Skills 目录。

## 最简单的使用方式

```text
请使用 doubao-ai-selling-video 这个 Skill，
为我上传的【产品名称】产品图制作一条 AI 带货视频的前期方案：
主播三视图、分镜脚本与分镜图、A-roll / B-roll 视频生成提示词。
```

也可以只给产品名称不给图，Agent 会自行补充卖点信息（建议标注哪些是推断）。

## 设计结构

```text
解析产品（产品档案，商品图单独放置作质检基准）
  → 主播方案（人设卡 + 主播三视图）
  → 分镜脚本（4-6 个分镜，含产品空镜）
  → 分镜图（五类画面，先生图再图生视频）
  → 逐张质检（结构物理常识 / 外观一致性 / 交互合理性 / 基础质量 / 肢体数量）
  → A-roll 口播提示词（换景别、禁前置动作、无背景音乐）
  → B-roll 辅助镜头提示词（含产品空镜，无背景音乐）
  → 可选：适配垫乐 + 混剪用法
```

详细提示词模板在 `doubao-ai-selling-video/references/prompt-templates.md`，按品类适配（美妆/食品/日用品/小家电/服饰）。

## 如何参与迭代

欢迎用这个 Skill 生成带货视频案例，并通过 GitHub Issue 提交复盘材料。建议 Issue 标题：

```text
[案例反馈] 产品类别 / 视频模型 / 时长
```

Issue 正文建议包含：产品类别、使用的视频模型与版本、实际提示词、成片视频链接、问题时间码、希望保留的部分、希望改进的结果。

请不要提交保密 brief、未获授权的客户素材、个人隐私或无法公开的视频。品牌名称与商标归各自权利人所有。

## 边界

- 这是前期制作与提示词编译 Skill，不保证任何平台的生成效果、参数上限或商业可投放性；
- 精确 Logo、包装小字、价格、CTA、免责声明和播出级旁白应由后期使用获批资产完成；
- 各视频模型的实际能力可能因入口和时间变化，使用前请以当前平台为准。
