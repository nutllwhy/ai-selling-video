# doubao-ai-selling-video（AI 带货视频前期制作）

## 概览

输入「产品名称 + 产品图片」，输出三件套：**主播方案（人设 + 主播图）、分镜脚本与分镜图、视频生成提示词（A-roll / B-roll）**。遵循"先生图、再图生视频"的约束思路：带货视频需要人物、商品、场景高度一致，直接文生视频容易翻车，因此先用分镜画面约束生成方向。

本 Skill 只管到"提示词 + 分镜图 + 主播图"这一层；最终视频生成与剪辑由用户在其他视频生成平台执行，不在此 Skill 范围内。Skill 产出的提示词**不绑定任何单一视频模型**——所有支持中文人声的视频模型（如 Vidu、可灵、即梦等）都可以直接使用，只需按平台差异微调少量参数。

## 工作流总览

| 步骤 | 产出 | 关键动作 |
|---|---|---|
| 0. 解析产品 | 产品档案 | 从名称+图片提取核心卖点、目标人群、画面可呈现性 |
| 1. 主播方案 | 主播人设 + 主播图（三视图） | 按品类选人设，生成 1 张三视图主播图（正面/侧面/背面同人物） |
| 2. 分镜脚本 | 4-6 个分镜脚本 | 每个分镜：画面、动作、台词、时长、卖点；口播讲解与产品空镜都要有 |
| 3. 分镜图 | 3-5 张分镜图 | 痛点/使用/推荐/效果/产品空镜五类，保持人物与商品一致 |
| 4. 视频提示词 | A-roll + B-roll 提示词 | A-roll 拆 2-3 段口播；B-roll 用分镜图做首帧，含产品空镜 |

全程遵循原则：
- **先做脚本检查，再动工**：卖点是否集中、台词是否自然、每个分镜是否能用画面表达。
- **竖屏 9:16**：带货视频统一按竖屏构图出图。
- **一致性优先**：主播和商品在全部分镜中保持同一形象，提示词中反复锚定主播人设与商品描述。
- **台词拆短**：口播不要一段塞满，拆成 2-3 段，避免后半段语速变快、口型翻车。

## Step 0：解析产品

- 读取用户提供的产品名称与产品图片；若图片是商品平铺图/详情页，提取：品类（美妆/食品/日用品/小家电/服饰等）、核心卖点（2-3 个）、目标人群、画面可呈现的形态（质地、包装、使用动作）。
- 输出「产品档案」：`产品名 / 品类 / 核心卖点 / 目标人群 / 推荐主播风格 / 可拍画面元素`。
- **商品图必须单独放置并标注为质检基准**：把用户提供的商品实拍图独立放入文档「产品档案」区块（不与其他生成图混排），标注"商品图｜所有分镜图中产品外观以此为准"。生成图数量越多越容易把 AI 生成的商品外观误当成参考，单独放置可避免参考错乱。
- 卖点不明确时，向用户确认 1 次核心卖点；其余细节按品类常识合理推断并在档案中标注"推断"。

## Step 1：生成主播方案

按品类选择主播人设，规则见 `references/prompt-templates.md` 的「主播人设模板」：

- 美妆/护肤 → 美妆博主（素颜或淡妆、居家、真实皮肤质感）
- 食品/饮料 → 美食博主/家庭主妇（亲切、餐桌或厨房、食欲感）
- 日用品/家居 → 生活博主（整洁家居、使用场景）
- 小家电/数码 → 科技生活博主（现代家居/桌面、演示动作）
- 服饰/穿搭 → 穿搭博主（衣橱/全身镜/街拍场景）

产出：
1. **主播人设卡**：年龄、性别、身份标签、场景、妆造、镜头表情（一句话）。
2. **主播图提示词**：按模板生成，竖屏 9:16，生活摄影风格、4K、真实感。
3. **主播图必须是人物三视图**（同一人物、同一妆造服装的正面/侧面/背面三格全身图），作为后续一致性的锚点。三视图能锁定人物多个角度的长相、体态、服装细节，后续分镜图用 `image_edit` 延展时人物不易变形；单张正面图在换角度延展时容易画崩。生成前必须读取 `doubao-creative-design` Skill 走完设计交付流程。
4. 三视图生成后按 Step 3.5 质检：三个角度必须是同一人、同一妆造服装、身体结构（每格肢体数量/手指数）正常。

## Step 2：生成分镜脚本

给用户输出 4-6 个分镜，每个分镜必须包含：

| 字段 | 说明 |
|---|---|
| 分镜号 | 1/2/3/4... |
| 类型 | 痛点画面 / 使用画面 / 推荐画面 / 效果画面 / 产品空镜（五类覆盖） |
| 时长 | 3-5 秒 |
| 画面 | 场景、人物动作、商品出现方式 |
| 台词 | 达人口播内容（若该镜头不开口则写"无"） |
| 卖点 | 本镜头负责传递的卖点 |

脚本风格要求：像真实达人种草，不像广告片。台词要口语化、有真实感，围绕核心卖点不散焦。

**节奏硬规则——开场必须"有声"**：短视频第 1 秒就要出口播，任何开场镜头不得静默（静默 2 秒即掉节奏）。若开场是痛点 B-roll：画面人物只做表情、不开口，台词以**画外音（另一条轨道）**形式在画面上响起，分镜台词栏写"（画外音）<台词>"；或直接以 A-roll 口播开场。后续 A-roll 口播台词与所承接画面的动作、场景必须一致（参考图里捧杯的画面，提示词就不能写整理衣领）。

**台词-时长匹配硬规则（写台词后必校验）**：口播语速按**每秒 4.5 字**核算，台词字数 ÷ 4.5 = 所需秒数，镜头时长必须 ≥ 所需秒数（留 0.5s 呼吸感更稳）。写完全部口播台词后，逐条列出「台词字数 → 需秒数 → 定秒数」对照核验，时长不足的镜头必须**压缩台词或加长镜头时长**，禁止出现"3s 镜头配 20+ 字台词"的赶拍。常用参考：5s≈22 字、4s≈18 字、3s≈13 字。

## Step 3：生成分镜图

- 五类画面按需覆盖：**痛点画面**（问题特写）、**使用画面**（涂抹/开箱/演示）、**推荐画面**（达人手持商品对镜头）、**效果画面**（治愈/放松/局部细节）、**产品空镜**（纯产品/场景氛围，无主播出镜）。
- **产品空镜必须有**：除了口播讲解（A-roll）和带人的分镜，成片还需要一些产品的空镜镜头——产品为主体、人物不入画或只在远景，靠场景氛围传达产品气质。空镜适合放在：痛点开头之后（展示产品第一眼）、口播之间（从讲解切到产品本身，缓解连续口播的单调）、收尾定格（氛围收束）。空镜也按「分镜图 → 图生视频」流程做：先出一张产品静物/场景氛围图作为首帧，再生成空镜视频；不依赖主播三视图锚点，但必须锚定商品图（产品外观、瓶盖、标签、相对大小都要对）。
- **一个画面只放一个分镜内容**：每张分镜图只承载一个镜头的内容，不做"左右分屏对比"拼图——分屏图作为 B-roll 首帧时两个内容各占半屏，参考和出片都不方便；需要前后对比时用两张独立图（痛点一张、效果一张）接续。
- 每张图用「分镜图提示词模板」（见 references）生成，模板中必须锚定 Step 1 选定的主播人设 + 商品描述，保证人物与商品一致（产品空镜锚定商品图即可，无需主播人设）。
- 竖屏 9:16，生活摄影风格、柔和自然光、4K、真实感。
- 调用图片生成工具出图（生成前读取 `doubao-creative-design` Skill），每张分镜图给出「画面意图 + 提示词 + 生成结果」。
- 分镜图是后续 B-roll 的首帧素材，必须选满意的画面，不要为凑数乱抽。
- 写「使用画面」提示词时，动作必须符合产品真实物理结构（见 Step 3.5），把结构常识直接写进提示词，不要只写笼统的"使用/喷/涂抹"。
- **产品相对大小必须写真实比例**：提示词中明确产品与手/人物的相对大小（如香水 30ml 小瓶"握在手中约占手掌一半，小巧纤细"），防止模型把产品画得过大；参考用户提供的产品图判断真实比例（30ml/50ml 香水、口红、小罐面霜等都是小巧单手持握），大件（大瓶身体乳、水桶装、家电）才占大面积。

## Step 3.5：生成后逐张质检（每张图生成后必须执行）

每生成一张主播图或分镜图，立即逐张检查，不合格的直接重抽该张，不允许带病交付（产品空镜图同样逐张质检：产品外观/标签/相对大小/场景氛围符合要求，画面无 AI 变形文字）。

**A. 产品结构物理常识检查**（最容易翻车，优先查）：
- 按压/喷洒类（香水、喷雾）：喷头必须外露才可能喷出液体——**瓶盖已取下放在一旁**，画面中出现按压喷头喷洒的动作；绝不允许"盖着盖子喷/盖着盖子按压"。
- 瓶装/管装护肤品：挤出动作时瓶口或管口必须打开（拧开的盖子/翻盖开启/挤压管口），不能隔着盖子挤出膏体。
- 罐装/盒装：打开、撕开、揭盖动作与状态一致；未开封时不应出现内部内容物。
- 食品/饮料：撕开包装、开瓶、倒出时，包装状态与动作结果吻合（撕了口才有内容物露出）。
- 电子/小家电：按开关、插电、亮屏等动作与产品结构一致（按钮位置、屏幕朝向、线材连接合理）。
- 服饰/鞋包：穿脱、拉链、系带、开合等动作与产品结构一致。

**B. 产品外观一致性检查**：
- 瓶身/包装形状、颜色、标签、容量标记等与用户提供的产品图一致，没有凭空多出或消失部件。
- 产品在每张分镜图中保持同一形态（尺寸比例、朝向合理）。
- **相对大小检查**：产品与手/人物的相对大小须符合真实比例——对照用户产品图与容量标记（如 30ml 香水=小巧小瓶，握在手中约占手掌一半）；产品被画得明显过大（几乎占满整只手/大得不像该容量）即为不合格，重抽并在提示词显式写"XXml 小瓶，握在手中约占手掌一半"。

**C. 人与产品交互合理性检查**：
- 持握方式符合产品尺寸与形状（小瓶单手、大罐双手、喷雾喷头朝向皮肤等）。
- 手部、手指位置与动作结果吻合（按压在喷头上、涂抹在皮肤上），无悬浮、错位、穿模。

**D. 画面基础质量检查**：
- 竖屏 9:16、风格统一（生活摄影、自然光、真实感）；人物形象与主播图一致；无明显穿帮（多余手指、变形文字、残缺部件）。

**E. 肢体与数量异常检查**（AI 生图高发问题，必须人工看图）：
- **禁止只依赖图片工具返回的文字描述做质检**——自动描述会漏报肢体数量、手部错位等问题。必须用 Read 工具打开生成的图片文件（必要时裁剪放大局部），人工逐张核对画面。
- 人物肢体数量：双手=两只、单手持物=一只手；数清可见的手/手指数量，出现第三只手、多余手指、手从奇怪位置伸出即为不合格。
- 手指形态：五指分布自然，无并指、无指节错位、无"橡皮泥手"。
- 人体结构：手臂与肩膀连接合理，无悬空肢体、无穿模（手穿进瓶身/衣服）。

不合格判定后：重抽该张图，并在新的提示词中显式写入正确的结构动作（如"瓶盖已取下放在一旁，露出喷头，手指按压喷头将香水喷洒在手腕上"）和肢体数量约束（如"画面中只有两只手：右手握瓶按压喷头，左手承接香水"），不得沿用出错的原因描述。

## Step 4：生成视频生成提示词

输出两类提示词，供用户在视频生成平台使用（A-roll 需支持中文人声/口播，B-roll 为纯画面素材）：

**A-roll（口播主线）**：2-3 段，每段对应分镜脚本中的台词，格式：

```
@<主播人设> 对着镜头讲话："<台词1>" 接着，拿出@<商品>，说："<台词2>"。温暖真诚的表情，自然动作，达人种草推荐风格
```

要点：台词拆成 2-3 段执行；每段以人物动作串接（拿出、涂抹、展示）；结尾落在产品名与推荐语。
- **所有提示词必须显式写"无背景音乐"**：AI 视频生成平台默认倾向配 BGM，不写约束几乎必出背景音乐。A-roll 每条末尾加"无背景音乐，纯人声"；B-roll 每条末尾加"无背景音乐，纯画面素材"。
- **A-roll 每段必须换景别**：中景（半身带动作）→ 近景（表情特写）→ 手持推荐（产品入画），避免"全是正面怼脸"的单调；每段提示词开头写明景别。
- **A-roll 禁止前置动作浪费时长**：提示词里不要写"微微回神后""缓缓抬头后""想了想"这类开场前置动作——口播段只有 3-4 秒，前置动作会吃掉 1-2 秒台词时间，必须"开场即开口/开口即说话"，动作（捧杯、托瓶）与说话同时进行。
- **口播不能覆盖全片**：成片 = A-roll 口播与 B-roll 纯画面穿插，B-roll 占比约一半。开场用痛点 B-roll 抓人、收尾用氛围 B-roll 定格品牌。
- **画外音不是独立生成的轨道**：所有台词都写在 A-roll 口播视频里（人物开口说话、自带音轨）；"画外音"是剪辑时把某段 A-roll 的音轨垫到 B-roll 素材画面上形成的效果。因此开场若先用 B-roll 痛点画面，要在交付里注明"剪辑时垫入哪段 A-roll 的音轨作画外音"，让第 1 秒就有声音，且这条音轨有真实视频承载。A-roll 提示词必须写完整台词（含被用作画外音的那句），B-roll 提示词只写画面动作、人物不开口。

**B-roll（辅助镜头）**：用满意的分镜图做首帧，4-5 秒，提示词只需写清"画面怎么动"，不写台词。格式：

```
首帧：<分镜图 N>。画面：<动作描述，如：手指将膏体以打圈方式按摩进脸颊，镜头缓慢推近>，柔和自然光线，真实博主风格
```

要点：动作幅度写具体（涂抹、开箱、翻转、推近、特写）；每条注明对应哪张分镜图；给 3-4 条覆盖节奏补镜头。
- **B-roll 要包含产品空镜**：除带主播的分镜画面外，至少安排 1-2 条产品空镜（产品为主体、无主播出镜或主播仅远景），如：香水瓶静置桌面/雪景松枝前/暖调窗台，镜头缓慢推近或环绕展示。空镜穿插在口播之间与收尾，让成片「有人讲解 + 有产品本身」，不全是主播对镜头讲。空镜同样用产品空镜分镜图做首帧，提示词只写产品/场景怎么动、不写台词。
- **B-roll 位置有讲究**：至少安排在开场 1 条（痛点抓人）、口播之间 1-2 条（遮瑕疵+提节奏）、收尾 1 条（氛围定格），不要全堆在结尾。
- **B-roll 提示词同样写"无背景音乐"**：B-roll 是纯画面素材，生成时同样可能被平台配上 BGM，必须显式写"无背景音乐，纯画面素材"，否则混剪时与口播音轨冲突。

**生成注意事项（交付时写明）**：即使提示词写了"无背景音乐"，部分视频生成平台（如 Vidu 等）仍会自动配 BGM。交付时提醒用户：①每条提示词务必完整复制、保留末尾禁音乐字样；②若平台有"配乐/背景音乐/BGM"开关，必须手动关闭；③生成后先试听确认无音乐再进入下一条，避免整批返工。

**可选：为成片生成一条适配背景音乐（垫乐）**：用户需要配乐时，用音频生成工具生成一条背景音乐，独立叠加在剪辑轨道上（不参与 A-roll/B-roll 的生成，不违反"无背景音乐"约束）。音乐风格按产品气质写（如木质香氛=钢琴分解和弦+温暖弦乐+极轻木质氛围音，清新向=轻快原声吉他），无人声无歌词，时长对齐成片总时长。交付时写明混剪用法：B-roll 纯画面段落垫乐可稍明显；A-roll 口播段落把音乐音量压低至约 15-20% 不压人声；收尾段落让音乐自然收尾、与定格品牌名同步。

## 交付格式

按以下结构一次性交付（文本即可，无需建文档，除非用户要求）：

```
产品档案
├─ 产品名 / 品类 / 核心卖点 / 目标人群
主播方案
├─ 人设卡
├─ 主播图提示词
└─ 主播图（生成的图片）
分镜脚本（表格：分镜号/类型/时长/画面/台词/卖点）
分镜图（每张：画面意图 + 提示词 + 图；含产品空镜图）
视频生成提示词
├─ A-roll 提示词 1/2/3
└─ B-roll 提示词 1/2/3/4（含首帧分镜图引用，其中至少 1 条为产品空镜）
背景音乐（可选，用户要配乐时）
└─ 适配垫乐 + 混剪用法（B-roll 段落明显、A-roll 段落 15-20% 不压人声、收尾与品牌名同步）
生成注意事项
└─ 提示词保留"无背景音乐"、关闭平台 BGM 开关、生成后试听
```

**建文档交付时：提示词与素材图用对照表格**（用户要求"放在文档里看清每个分镜用什么参考图"时必做）：
- 列为「视频段｜素材图｜提示词」，每行嵌入对应素材图：A-roll 用主播三视图锚点，B-roll 用该镜头对应的分镜图。
- 提示词与素材图必须同格呈现、一一对应，不要拆成两处让用户来回找。

## 质量检查（交付前自查）

- [ ] 主播人设与商品品类匹配，主播图人物形象清晰一致
- [ ] 分镜覆盖五类画面（痛点/使用/推荐/效果/产品空镜），卖点不散焦，至少含 1 条产品空镜
- [ ] 每个分镜都有可执行的画面描述，台词口语化、像真实种草
- [ ] A-roll 台词已拆段，B-roll 每条都指明"画面怎么动"并关联首帧分镜图
- [ ] 所有图片竖屏 9:16，风格统一（生活摄影、自然光、真实感）
- [ ] **每张图已通过 Step 3.5 逐张质检**：产品结构物理常识（喷头/盖子/开口/开关与动作吻合）、产品外观与产品图一致、人与产品交互合理、无穿帮、**肢体数量正常（无多手/多指/错位，已用 Read 打开图片人工核对，而非只看工具描述）**
