# 提示词模板库（按品类适配）

本文件沉淀自《公司内训版｜500积分做一条AI真人带货视频》《教程｜AI真人带货视频做法全公开！Image2+ViduQ3高效出片》的实战提示词。所有模板遵循：竖屏 9:16、生活摄影风格、柔和自然光、4K、真实感；主播与商品提示词中反复锚定，保证跨镜头一致性。

## 1. 主播人设模板（按品类）

选品类 → 套人设 → 生成主播图提示词。数字（年龄）可按商品目标人群微调。

**主播图统一用人物三视图**（同一人物、同一妆造服装的正面/侧面/背面三格全身图，可拼在一张横图或三张独立图），三视图能锁定人物多个角度的形象，后续分镜延展不易变形。三视图格式骨架：

```
同一亚洲{女性/男性}的全身三视图，从左到右依次为：正面全身、右侧面全身、背面全身，三格人物形象、妆造、服装完全一致，{年龄}岁左右，{品类}博主，{场景}，{穿着}，自然窗光照射，{表情状态}，柔和自然光线，生活摄影风格，4K，真实感
```

### 美妆 / 护肤
```
一位{28}岁左右的亚洲女性，美妆博主，坐在明亮的卧室里，自然窗光照射，穿着休闲家居服，素颜，脸颊可见轻微{干燥/细腻}的皮肤纹理，对着镜头温暖微笑，柔和自然光线，生活摄影风格，4K，真实感
```
- 人设卡示例：28岁美妆博主 / 居家素颜 / 卧室自然光 / 温暖微笑 / 真实皮肤质感
- 变体：敏感肌→强调"泛红但皮肤状态真实"；抗老→年龄上浮到 35-40，场景可换"现代浴室"

### 食品 / 饮料
```
一位{30}岁左右的亚洲女性，美食博主，坐在明亮温馨的餐桌前，自然窗光照射，桌上摆着{产品}，她对着镜头亲切微笑，准备品尝，柔和自然光线，生活摄影风格，4K，真实感
```
- 人设卡示例：30岁美食博主 / 餐桌场景 / 亲切笑容 / 食欲感
- 变体：家庭装→"家庭主妇"人设+厨房场景；零食→"年轻女生"人设+沙发/书桌场景

### 日用品 / 家居
```
一位{32}岁左右的亚洲女性，生活博主，站在明亮整洁的现代客厅里，自然窗光照射，穿着舒适的家居服，手持{产品}，对着镜头自然微笑，生活摄影风格，柔和自然光线，4K，真实感
```
- 人设卡示例：32岁生活博主 / 现代客厅 / 手持产品 / 自然微笑

### 小家电 / 数码
```
一位{28}岁左右的亚洲男性，科技生活博主，坐在明亮现代的工作台前，自然窗光照射，桌上放着{产品}，他对着镜头自信介绍，生活摄影风格，柔和自然光线，4K，真实感
```
- 人设卡示例：28岁科技博主 / 工作台场景 / 演示动作 / 自信表情
- 变体：女性向产品可换"年轻女性科技博主"

### 服饰 / 穿搭
```
一位{25}岁左右的亚洲女性，穿搭博主，站在明亮简约的衣橱前，自然窗光照射，穿着{产品}，摆出自然随性的姿势，对着镜头微笑，生活摄影风格，柔和自然光线，4K，真实感
```
- 人设卡示例：25岁穿搭博主 / 衣橱或全身镜 / 随性姿势 / 微笑

## 2. 分镜图提示词模板（五类画面）

每张分镜图 = 主播锚点 + 商品锚点 + 画面动作 + 风格后缀。风格后缀统一为：`柔和自然光线，生活摄影风格，4K，真实感`。产品空镜只锚定商品图（产品外观/标签/相对大小以此为准），不锚定主播人设。

### 2a. 痛点画面（问题特写）
```
{主播人设} 坐在{场景，如堆满文件的办公桌前}，{状态描写，如平静地疲惫：眼睛放空、双手捧杯发呆}，{痛点道具特写，如凌乱文件/咖啡杯}，柔和自然光线，{品类}场景，4K，真实感
```
- **一个画面只放一个分镜内容**：痛点画面单独一张、治愈/效果画面单独一张，不要做"左右分屏对比"拼图——分屏图作为 B-roll 首帧时两个内容各只占半屏，参考和出片都不方便。需要前后对比时，用两个独立分镜图（痛点一张、效果一张）接续呈现。
- 表情克制：痛点表情写"平静的倦怠/轻微疲惫"，不写夸张痛苦表情（皱眉瞪眼、扶额张嘴都会显得吓人，不像真实生活）。
- 非护肤品类：痛点可为"凌乱的书桌/堆满的衣服/手忙脚乱"等单场景。
- **开场痛点画面必须"有声"**：短视频第 1 秒就要出口播，开场 B-roll 不能静默（会掉节奏）。两种做法：①痛点画面只给人物表情、不开口，这句台词作为**画外音（另一条轨道）**在画面上响起；②直接以 A-roll 口播开场。配套规则：画面人物不开口时，台词写"（画外音）"；B-roll 提示词里写明"人物不说话，声音由画外音轨道提供"。

### 2b. 使用画面（产品被真实使用）
```
年轻{亚洲女性/亚洲男性}@{主播人设} 穿着{服装}，坐在{明亮现代浴室/明亮客厅/温馨餐桌前/工作台前}，自然窗光照射，正在{使用动作，如涂抹{产品}在手臂/打开包装/按下开关/试穿}，日常{品类}时刻，生活摄影，柔和自然光线，4K，真实{品类}博主美学
```
- 使用动作按品类替换：护肤→涂抹、食品→品尝/撕开、日用品→擦拭/整理、小家电→按键/操作、服饰→整理衣领/转身
- **【产品相对大小，必写进提示词】** 提示词必须写明产品与手/人物的相对大小（如香水 30ml 小瓶"握在手中约占手掌一半，小巧纤细"、30/50ml 香水或口红"单手持握的小巧尺寸"），防止模型把产品画得过大。参照用户产品图上的容量标记判断真实比例：小容量护肤/香氛产品是单手持握的小瓶，大件产品（大容量身体乳、水桶装、家电）才占大面积。
- **【产品结构常识，必写进提示词】** 使用动作必须与产品真实物理结构一致，直接写入画面描述，避免 AI 画出物理错误：
  - 按压/喷洒类（香水、喷雾）：先写"瓶盖已取下放在一旁，露出喷头"，再写"手指按压喷头喷洒"。禁止出现盖着盖子喷。
  - 瓶装/管装护肤品：写"拧开瓶盖/翻开盖子，挤出膏体到指尖/手心"，再写涂抹动作。
  - 罐装/盒装食品：写"撕开/揭开包装，露出内容物"，再写品尝/倒出。
  - 小家电/数码：写清按钮、开关、屏幕、接口的朝向与操作位置（如"按下侧面的圆形按钮""点亮屏幕"）。
  - 服饰/鞋包：写清拉链、纽扣、系带等开合结构与动作。
- 每次生成后必须对照 SKILL.md Step 3.5 逐张质检，不合格重抽。

### 2c. 推荐画面（达人手持产品对镜头）
```
年轻{亚洲女性/亚洲男性}@{主播人设} 手持{产品名}{产品}@{商品}（{真实相对大小，如 30ml 小瓶，小巧纤细，约占手掌一半}），对着镜头温暖微笑，坐在{明亮卧室/餐桌/客厅/工作台}里，自然窗光照射，穿着{服装}，真实{品类}博主推荐风格，柔和自然光线，4K，真实感
```
- 这是全片最重要的"转化镜头"，表情要求自然真诚，像真实种草，不像广告
- 手持展示同样写明产品真实相对大小（小瓶单手持握、小巧纤细），避免瓶子被画成占满手掌的大瓶。

### 2d. 效果画面（结果 / 细节特写）
```
{主播人设} 用手指将{产品质地描述，如白色膏体}涂抹在{部位}上，坐在{场景}里，自然窗光照射，温柔的{使用}时刻，真实{品类}博主风格，柔和自然光线，4K，真实感
```
- 或局部特写变体：`{产品名}{商品}的{质地/细节}局部特写，展示{卖点，如厚实但不油腻/大容量/细腻质感}，柔和自然光线，4K，真实材质细节`
- 捧/托/嗅类效果画面同样写明产品真实相对大小（小巧瓶身、约占手掌一半），并保留结构常识（嗅闻时瓶盖可取下或闭合状态与动作一致）。

### 2e. 产品空镜画面（纯产品/场景氛围，无主播出镜）
```
{产品名}{商品}（{真实相对大小，如 30ml 小瓶，小巧纤细}）静置于{场景，如木质桌面/雪覆松枝前/暖调窗台/大理石台面}，{场景氛围描写，如背景暖调虚化/窗外雪景/自然光洒落}，柔和自然光线，生活摄影风格，4K，真实感
```
- 这是成片必备的"产品空镜"：产品为主体、人物不入画（或只在远景），靠场景氛围传达产品气质，与口播讲解穿插，缓解连续口播的单调。
- 空镜首帧必须锚定用户提供的商品图（瓶身/瓶盖/标签/相对大小完全一致），生成后同样走 Step 3.5 质检。
- 场景与产品气质绑定：木质调香氛→木质桌面/暖调室内；清新类→绿植/窗台自然光；冬日感→雪景/冷调；高端感→大理石/简洁台面。产品相对大小保持真实（30ml 小瓶约占手掌一半，不要被画成占满画面的大瓶）。
- 位置建议：痛点后接第一眼产品空镜、口播之间插产品空镜、收尾用氛围空镜定格。

## 3. A-roll 口播提示词模板（拆 2-3 段）

格式骨架：`@{主播人设} 对着镜头讲话："{开场痛点台词}" 接着，她/他拿出@{商品}，说："{产品名+卖点+推荐语}" 温暖真诚的表情，自然动作，{品类}博主推荐风格`

拆分原则：
- 段1 = 痛点开场（1-2 句，抓人）
- 段2 = 产品亮相 + 1-2 个卖点（容量/质地/成分等具体数字或感官描述）
- 段3 = 效果承诺 + 产品名收尾推荐（"xxx真的很好用/很值得"）

示例（护肤品类，来自实战）：
```
@美妆博主对着镜头讲话："最近换季，皮肤又干又泛红" 接着，她拿出@大白罐，说："还好有这个，xxx大白罐，550克超大容量，质地像冰淇淋一样，厚实但不油腻。" 温暖真诚的表情，自然动作，美妆博主推荐风格，无背景音乐，纯人声
```
```
@美妆博主 把@大白罐 的白色膏体擦到脸上，说："一抹就化开了，吸收很快，不粘腻，早晚涂一涂，泛红、粗糙都能改善，无香精无酒精，全家都能用，一罐能用很久。xxx大白罐，真的很好用" 温暖真诚的表情，自然动作，美妆博主推荐风格，无背景音乐，纯人声
```

台词写作要点：
- 卖点给具体数字或感官词（容量、时长、质地比喻），不写空泛形容词
- 结尾重复产品名 + 一句强烈推荐语
- 全片 10-20 秒：总台词控制在 2-4 句，拆成 2-3 段生成，不要一段塞满
- **台词长度按语速配时长**：口播按每秒 4.5 字核算（5s≈22 字、4s≈18 字、3s≈13 字），写完逐条列「字数→需秒数→定秒数」对照，时长不够就压缩台词或加长镜头，禁止赶拍

## 4. B-roll 辅助镜头提示词模板（图生视频）

格式骨架：`首帧：{分镜图 N}。画面：{动作描述}，柔和自然光线，真实{品类}博主风格`

动作描述要写"画面怎么动"，给 3-4 条：

| 用途 | 动作描述示例 |
|---|---|
| 产品使用 | 手指将膏体以打圈方式按摩进脸颊，镜头缓慢推近 |
| 商品展示 | 双手将产品从包装中取出，缓缓转向镜头展示正面，轻微旋转 |
| 产品空镜 | 香水瓶静置桌面上，镜头缓慢推近瓶身特写，光线在玻璃瓶身上流转；或镜头环绕产品缓缓移动，背景氛围（雪景/暖调）逐渐清晰 |
| 细节特写 | 镜头缓慢靠近产品质地局部，焦点从背景过渡到产品表面 |
| 自然转场 | 画面从商品特写缓缓拉远到博主微笑全身，自然过渡 |

B-roll 动作描述同样要符合产品结构常识（按压类镜头须先呈现"瓶盖已取下、喷头外露"，再写按压喷洒动作；开盖、撕包、按键动作与产品结构一致），并在成片后按 Step 3.5 逐段检查首帧与动作的吻合度。

要点：
- 每条 B-roll 4-5 秒即可
- 提示词只写动作，不写台词
- **每条必须写"无背景音乐，纯画面素材"**：B-roll 是混剪素材，平台默认配 BGM 会与口播音轨冲突
- 必须用满意的分镜图做首帧，不要文生视频硬赌
- 动作幅度写具体、写小（"轻微""缓缓"），避免大幅运动翻车
- **至少安排 1-2 条产品空镜**：产品为主体、无主播出镜（或远景），穿插在口播之间与收尾；空镜提示词同样写"无背景音乐，纯画面素材"，首帧用产品空镜分镜图

## 5. 通用风格后缀

所有图片/视频提示词统一追加（按需组合）：
```
柔和自然光线，生活摄影风格，4K，真实感
```
视频场景可加：`自然动作，温暖真诚的表情，达人种草推荐风格（不要像广告片）`

**视频提示词音频硬规则（必加）**：
- A-roll（口播带音轨）：末尾必须加 `无背景音乐，纯人声`
- B-roll（纯素材）：末尾必须加 `无背景音乐，纯画面素材`
- AI 视频平台默认倾向配 BGM，不写约束必出背景音乐，混剪时会与口播冲突；每一条提示词都不能漏。
